# Giftly Image + Design Guidelines

## Image placement
- Hero: one large lifestyle image, never a product thumbnail collage.
- Circular category rails: one distinct photograph per category.
- Product cards: square crop, product-led photography, consistent object-fit cover.
- Wedding culture: people/ritual/cultural-detail photography.
- Wedding state cards: location/venue/ritual/decor photography.
- Hampers: front/three-quarter or top-down gift-box photography.
- Personalised: gift-box, keepsake, photo-frame or custom-product photography.
- Offers: wide lifestyle/promotional imagery with strong negative space for text.

## Color
- Primary pink: #D6336C
- Dark pink: #A61E4D
- Soft pink: #FDEEF2
- Soft blue: #EAF4FB
- Ink: #2B2130
- Muted: #7A6B72

## Merchandising rhythm
Hero -> Trust -> Categories -> Wedding Spotlight -> Special Days -> Best Sellers -> Recipients -> Wedding Combos -> Personalised -> Hampers -> Anniversary -> Feelings -> Luxe -> New Arrivals -> Budget -> Offers -> SEO story.

## Avoid
- Repeating the same photo several times in one section.
- Mixing illustration styles inside a single rail.
- Using competitor logos or copied text.
- Overloading the homepage with the complete wedding catalogue.
- Introducing new top-level navigation categories outside the locked six: Wedding, Occasions, Anniversary, Hampers, Personalised, Lifestyle.
