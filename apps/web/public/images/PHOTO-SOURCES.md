# Giftly image sources

The storefront uses a one-to-one image key system so the same photograph is not intentionally reused within a single section. The browser first looks for `/images/photos/<key>.jpg`, then uses the Pexels URL, then a local SVG fallback.

The selected Pexels pages used for the image manifest are marked free to use on Pexels. Review the current Pexels license before production use.
